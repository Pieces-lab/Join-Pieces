# Contributing

[简体中文](CONTRIBUTING.zh-CN.md)

This repository accepts applications to join the organization and updates to existing member entries.

## Apply to join

- Open an issue with the [application template](.github/ISSUE_TEMPLATE/join.md). Include the name you want displayed, your GitHub username, and a short reason for joining.
- Fork the repository and add one row to the **Members** table in both [English](README.md) and [Chinese](README.zh-CN.md) READMEs. Keep the same member order and GitHub link in both files. Add your row after the current last member. The example tables are for reference only.
- Use your name or nickname, a link to your GitHub profile, and a brief reason for joining. Leave the join date as `—`; the repository owner will fill it in when merging your PR.
- Open a PR using the [PR template](.github/pull_request_template.md). Replace `ISSUE_NUMBER` in `Closes #ISSUE_NUMBER` with your application issue number.

## Keep the member list in order

Several applicants may edit the table at the same time. Before opening your PR, sync your branch with the latest `main`. Check again before merging if another PR was merged first. Keep all existing rows, put yours after the current last member, and resolve any conflicts in both README files. GitHub does not automatically move your row below newly merged entries.

If you are already a member, you can open a PR to update your own entry. Keep the English and Chinese tables in sync.
