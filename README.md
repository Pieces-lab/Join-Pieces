# Join Pieces

这里记录已加入组织的成员，也作为申请加入组织的入口。每位成员可以在自己的记录中介绍个人经历、做过的项目和作品，让大家更容易认识彼此。

## 如何加入

1. 新建一个 issue，简单介绍自己，并说明想加入组织的原因。
2. Fork 本仓库，按下方格式在「成员」一节添加自己的记录，然后提交 PR。
3. 在 PR 描述中关联申请 issue，例如填写 `Closes #123`。
4. 仓库作者查看申请。PR 合并后，作者会为申请人提供一个组织专用仓库，用来持续记录和展示自己的内容。

## 成员

提交 PR 时，请在这里添加一条记录，并把示例中的信息换成自己的内容：

```markdown
### 你的名字或昵称

- GitHub：[@你的用户名](https://github.com/你的用户名)
- 关于我：一句话介绍自己和相关经历。
- 项目与作品：[项目名称](项目链接) — 简单说明你做了什么。
- 其他链接：博客、作品集等（可选）。
```

经历、项目和作品可以只填写自己愿意分享的部分。加入后，也可以通过 PR 更新这里的记录；更完整的内容可以写在自己的组织专用仓库中。
